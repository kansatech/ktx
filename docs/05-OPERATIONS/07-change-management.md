# Host Change Record

For Host Core changes record at least:

- UTC date/time;
- reason;
- old Host Core release;
- new Host Core release;
- native component versions changed;
- Ubuntu/Docker package versions if relevant;
- build test result;
- dev test result;
- prod deployment time;
- rollback required?;
- notes.

This is not bureaucracy. It is the answer to "what changed right before every website stopped responding?"
