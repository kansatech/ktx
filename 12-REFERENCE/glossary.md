# Glossary
**Artifact** — exact image/release file produced on build and promoted unchanged.  
**Recreate** — replace container instance from configured image while preserving external state.  
**Restart** — stop/start same instance.  
**Site network** — private bridge for one site plus required shared services.  
**ACME** — certificate issuance/renewal protocol used by Traefik.  
**SSHPiper** — SSH reverse proxy routing usernames to site sshd endpoints.  
**Restic** — encrypted deduplicating backup tool.
